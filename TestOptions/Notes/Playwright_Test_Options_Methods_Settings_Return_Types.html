Playwright Test Options

Important methods and settings · one-line usage · TypeScript types and return types

How to read the type column: For methods, it shows the return type. For configuration settings and CLI options, there is no method return value; the column shows the expected value type or identifies it as a configuration/CLI option. Async methods return Promises, so use await in tests.

1. Test discovery and configuration

testDir

Sets the directory where Playwright searches for test files.

Type / return: string

Configuration setting — no return value.

testMatch

Selects test files whose paths match the supplied pattern(s).

Type / return: string | RegExp | Array<string | RegExp>

Configuration setting — no return value.

testIgnore

Excludes matching test file paths from discovery.

Type / return: string | RegExp | Array<string | RegExp>

Configuration setting — no return value.

defineConfig(config)

Provides typed configuration for the exported Playwright Test config.

Type / return: PlaywrightTestConfig

Returns the configuration object; it does not execute tests.

test.use(options)

Applies fixture/use options to tests in the current file or describe scope.

Type / return: void

Returns void.

test.setTimeout(ms)

Changes the timeout for the current test or applicable hook.

Type / return: void

Returns void.

2. Browser and session use settings

use.browserName

Chooses the browser engine for a project or default test configuration.

Type / return: 'chromium' | 'firefox' | 'webkit'

Configuration setting — no return value.

use.headless

Runs the browser without a visible graphical window when true.

Type / return: boolean

Configuration setting — no return value.

use.baseURL

Provides the base URL used to resolve relative navigation URLs.

Type / return: string

Configuration setting — no return value.

use.viewport

Sets the page viewport dimensions in CSS pixels; null disables the fixed viewport.

Type / return: { width: number; height: number } | null

Configuration setting — no return value.

use.storageState

Loads cookies and local storage state to start a test in a prepared session.

Type / return: string | StorageState

Configuration setting — no return value.

use.locale

Sets the browser context locale, affecting locale-sensitive behaviour.

Type / return: string

Configuration setting — no return value.

use.timezoneId

Sets the browser context time zone.

Type / return: string

Configuration setting — no return value.

use.permissions

Grants specified browser permissions to the context.

Type / return: string[]

Configuration setting — no return value.

use.ignoreHTTPSErrors

Allows navigation to sites with invalid or untrusted HTTPS certificates when true.

Type / return: boolean

Configuration setting — no return value.

use.actionTimeout

Sets the default timeout in milliseconds for Playwright actions that support it.

Type / return: number

Configuration setting — no return value.

use.navigationTimeout

Sets the default timeout in milliseconds for navigation operations.

Type / return: number

Configuration setting — no return value.

use.screenshot

Controls when automatic test screenshots are captured.

Type / return: 'off' | 'on' | 'only-on-failure'

Configuration setting — no return value.

use.video

Controls video recording and retention for test runs; supported values depend on Playwright version.

Type / return: 'off' | 'on' | 'retain-on-failure' | 'on-first-retry' | 'retain-on-first-failure'

Configuration setting — no return value.

use.trace

Controls when Playwright trace files are recorded and retained; check installed-version support.

Type / return: 'off' | 'on' | 'retain-on-failure' | 'on-first-retry' | 'on-all-retries' | 'retain-on-first-failure'

Configuration setting — no return value.

3. Execution and timeout settings

timeout

Sets the maximum duration in milliseconds for an individual test.

Type / return: number

Configuration setting — no return value.

expect.timeout

Sets the default maximum wait time for web-first assertions.

Type / return: number

Configuration setting — no return value.

workers

Sets the maximum number of worker processes used for parallel test execution.

Type / return: number | string

Configuration setting — no return value.

retries

Sets how many additional attempts are allowed after a test fails.

Type / return: number

Configuration setting — no return value.

maxFailures

Stops scheduling further tests after the configured number of test failures is reached.

Type / return: number

Configuration setting — no return value.

fullyParallel

Allows tests within files to run in parallel, subject to project and test configuration.

Type / return: boolean

Configuration setting — no return value.

forbidOnly

Fails the test run if test.only or describe.only is present.

Type / return: boolean

Configuration setting — no return value.

failOnFlakyTests

Makes flaky tests cause the run to fail; confirm support in the installed Playwright version.

Type / return: boolean

Configuration setting — no return value.

test.setTimeout(ms)

Overrides the timeout for the current test or hook.

Type / return: void

Returns void.

test.slow()

Marks the current test as slow and triples its timeout.

Type / return: void

Returns void.

4. Projects, hooks and fixtures

projects

Defines named configurations such as Chromium and Firefox that run the test suite.

Type / return: TestProject[]

Configuration setting — no return value.

project.dependencies

Makes a project wait for the named dependency projects to complete successfully.

Type / return: string[]

Configuration setting — no return value.

test.beforeAll(fn)

Registers a hook that runs before tests in its file or describe scope, once per worker for that scope.

Type / return: void

Returns void.

test.afterAll(fn)

Registers a hook that runs after tests in its file or describe scope, once per worker for that scope.

Type / return: void

Returns void.

test.beforeEach(fn)

Registers a hook that runs before each test.

Type / return: void

Returns void.

test.afterEach(fn)

Registers a hook that runs after each test.

Type / return: void

Returns void.

test.describe(title, fn)

Groups related tests and optionally scopes hooks or configuration.

Type / return: void

Returns void.

test.skip()

Marks the current test as skipped; the test body is not run when skip is applied before execution.

Type / return: void

Returns void.

test.fixme()

Marks a test as not ready or known to be broken so it is skipped.

Type / return: void

Returns void.

test.fail()

Marks a test as expected to fail; an unexpected pass is reported as a failure.

Type / return: void

Returns void.

test.step(title, fn)

Runs a callback as a named test step and returns the callback's resolved value.

Type / return: Promise<T>

Returns a Promise of the callback result.

5. Assertions and locator methods

expect(actual)

Starts an assertion against a value, locator, page or response.

Type / return: Expectation object

Returns an expectation object; the selected matcher returns a Promise.

await expect(locator).toBeVisible()

Waits until the locator resolves to a visible element or the assertion times out.

Type / return: Promise<void>

Returns Promise<void>.

await expect(locator).toHaveText(text)

Waits until the locator's text matches the expected text.

Type / return: Promise<void>

Returns Promise<void>.

await expect(locator).toHaveCount(count)

Waits until the locator matches the expected number of elements.

Type / return: Promise<void>

Returns Promise<void>.

await expect(page).toHaveURL(url)

Waits until the page URL matches the expected URL.

Type / return: Promise<void>

Returns Promise<void>.

page.getByRole(role, options?)

Finds an element by its accessible role and optional accessible name.

Type / return: Locator

Returns Locator.

page.getByText(text, options?)

Finds elements by their text content.

Type / return: Locator

Returns Locator.

page.getByLabel(text, options?)

Finds a form control by its associated label.

Type / return: Locator

Returns Locator.

page.getByPlaceholder(text, options?)

Finds an input by its placeholder text.

Type / return: Locator

Returns Locator.

page.getByTestId(testId)

Finds an element using its configured test ID attribute.

Type / return: Locator

Returns Locator.

locator.locator(selector)

Creates a locator relative to the current locator, useful for chaining and narrowing scope.

Type / return: Locator

Returns Locator.

locator.filter(options)

Narrows a locator using conditions such as hasText, has or hasNot.

Type / return: Locator

Returns Locator.

locator.first() / last() / nth(index)

Selects the first, last or zero-based indexed match.

Type / return: Locator

Returns Locator.

locator.count()

Returns the current number of elements matched by the locator.

Type / return: Promise<number>

Returns Promise<number>.

locator.isVisible()

Checks visibility immediately without auto-waiting for the element to become visible.

Type / return: Promise<boolean>

Returns Promise<boolean>.

locator.click()

Waits for actionability and clicks the matched element.

Type / return: Promise<void>

Returns Promise<void>.

locator.fill(value)

Fills an input or editable element with the supplied value.

Type / return: Promise<void>

Returns Promise<void>.

locator.textContent()

Reads the element's textContent; returns null if the value is null or no element is available under the method's rules.

Type / return: Promise<string | null>

Returns Promise<string | null>.

locator.getAttribute(name)

Reads the requested attribute from the matched element.

Type / return: Promise<string | null>

Returns Promise<string | null>.

6. Browser, context, page and event methods

browser.newContext(options?)

Creates an isolated browser context with its own cookies and storage.

Type / return: Promise<BrowserContext>

Returns Promise<BrowserContext>.

browser.newPage()

Creates a new page in a new browser context; mainly convenient for short standalone scripts.

Type / return: Promise<Page>

Returns Promise<Page>.

context.newPage()

Creates a new page inside the existing browser context.

Type / return: Promise<Page>

Returns Promise<Page>.

context.pages()

Returns the pages currently open in the browser context.

Type / return: Page[]

Returns Page[].

page.goto(url)

Navigates the page to a URL and returns the main resource response, or null in cases such as a same-document navigation.

Type / return: Promise<null | Response>

Returns Promise<null | Response>.

page.url()

Returns the current page URL.

Type / return: string

Returns string.

page.title()

Returns the current page title.

Type / return: Promise<string>

Returns Promise<string>.

page.reload()

Reloads the current page.

Type / return: Promise<null | Response>

Returns Promise<null | Response>.

page.waitForEvent('popup')

Waits for a popup opened by this page, such as a link that opens a new tab/window.

Type / return: Promise<Page>

Returns Promise<Page>.

context.waitForEvent('page')

Waits for a new page opened anywhere in this browser context.

Type / return: Promise<Page>

Returns Promise<Page>.

page.close()

Closes the page.

Type / return: Promise<void>

Returns Promise<void>.

context.close()

Closes the browser context and its pages.

Type / return: Promise<void>

Returns Promise<void>.

browser.close()

Closes the browser and its contexts.

Type / return: Promise<void>

Returns Promise<void>.

7. CLI, reporting and output settings

--project

Runs tests in the named project or projects.

Type / return: CLI option

Command-line option — no JavaScript return type.

--grep

Selects tests whose titles or associated metadata match a regular expression.

Type / return: CLI option

Command-line option — no JavaScript return type.

--grep-invert

Excludes tests whose titles or associated metadata match a regular expression.

Type / return: CLI option

Command-line option — no JavaScript return type.

--workers

Overrides the configured worker count for a test run.

Type / return: CLI option

Command-line option — no JavaScript return type.

--shard

Runs one shard of the test suite, for example --shard=1/4.

Type / return: CLI option

Command-line option — no JavaScript return type.

reporter

Selects result reporters such as list, html or junit.

Type / return: Reporter configuration

Configuration setting — no return value.

outputDir

Sets the directory for test-run output such as attachments and artifacts.

Type / return: string

Configuration setting — no return value.

preserveOutput

Controls which test output directories are preserved after a run.

Type / return: 'always' | 'failures-only' | 'never'

Configuration setting — no return value.

snapshotPathTemplate

Customizes the path pattern for expected snapshot files.

Type / return: string

Configuration setting — no return value.

Accuracy and scope: This reference is based on the Playwright Test Options concepts covered in your learning checklist, with related frequently used methods added to make the reference practical. Some option unions and newer settings vary by Playwright version; verify against the version installed in your project. The listed types are concise TypeScript-facing summaries, not full declaration-file signatures. Configuration options are values, not methods, so they do not have return types.
